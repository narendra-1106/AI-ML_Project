About the Project

Technical architecture, methodology, machine learning model details, and viva reference guide.

📌

Problem Statement

Cricket match outcomes depend on multiple pre-match and in-game factors. The objective of this project is to build a machine learning model capable of predicting the winner of an IPL match based on historical match parameters such as competing teams and toss decisions.

🎯

Project Objectives

  • Preprocess and standardize historical IPL match data across seasons.
  • Build a Scikit-Learn pipeline with OneHotEncoder and Decision Tree Classifier.
  • Evaluate real classification metrics (Accuracy, Precision, Recall, F1-Score).
  • Deploy an interactive web application with Flask and SQLite database persistence.
📁

Dataset Specifications

The dataset (matches.csv) consists of 1,212 historical IPL matches spanning from 2008 to 2024/2025. It includes match parameters, team names, toss decisions, and final match outcomes across 13 active franchises.

🌲

Machine Learning Algorithm

Supervised Classification: Decision Tree Classifier
The model splits decision nodes based on Information Gain / Entropy. Features are transformed using a ColumnTransformer with OneHotEncoder wrapped inside a unified Scikit-learn Pipeline.

Future Enhancements & Scope

Future iterations of this project can incorporate live venue pitch analytics, weather conditions, player ELO ratings, detailed ball-by-ball player performance, and ensemble models (Random Forest, XGBoost) to further increase predictive accuracy.
